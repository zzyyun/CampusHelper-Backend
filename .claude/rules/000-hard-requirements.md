## 安全
- 禁止将 secrets、密码、API key 写入代码或提交到 Git
- 禁止使用 eval()、exec() 等动态代码执行（除非有明确业务需求且经 Review 批准）
- 用户输入必须在系统边界做校验，不信任前端传入的任何数据
- gRPC 接口仅限内网调用，禁止暴露到公网

## 架构边界
- 多租户隔离：所有业务查询必须带 `school_id` 条件，禁止跨校数据访问
- 每个微服务拥有独立 MySQL 数据库，禁止跨服务直连数据库
- 微服务间只通过 gRPC 通信，禁止直接访问其他服务的数据库或内部结构
- 公共组件放 `pkg/`，业务逻辑放 `internal/`，严禁在 `pkg/` 中包含业务代码
- MQ 消息必须携带 TraceID，保证全链路可追踪

## 代码注释
- 所有代码注释使用简体中文
- 函数、核心逻辑、复杂代码块必须添加注释
