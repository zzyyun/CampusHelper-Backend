## 测试命令
- `go test ./... -v` — 运行全部测试
- `go test ./... -race` — 含竞态检测（CI 中使用）

## 覆盖率
- 新增代码覆盖率要求：≥ 80%
- 关键路径（认证、多租户隔离、数据修改）覆盖率要求：≥ 90%

## 测试结构
- 测试文件与源文件同目录，命名 `*_test.go`
- 测试用例按功能分组，使用子测试（`t.Run`）
- 外部依赖（数据库、MQ、HTTP）使用 mock，不依赖真实服务
- gRPC 服务测试使用 `bufconn` 本内存连接，不占用真实端口

## CI 集成
- 每次 push / PR 自动运行 `go vet` + `go test -race`
- 测试失败阻止镜像构建和合入
- golangci-lint 静态分析失败阻止合入
